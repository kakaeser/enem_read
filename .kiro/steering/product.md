# Product Overview

"Enem da Read" is a desktop application for managing quiz/exam sessions with participants. The application provides:

- Attendance tracking with presence list management
- Question/answer management for each participant
- Real-time ranking system based on participant scores
- Excel import/export functionality for participant lists and rankings
- Dark-themed GUI interface

The application is designed for educational environments where instructors need to track student attendance, manage quiz responses, and generate rankings.
